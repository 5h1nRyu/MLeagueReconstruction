# 首页复刻实现说明

参考页面：https://m-league.jp/ 。观察日期：2026-10-09。

## 范围

实现首页及其滚动区域、菜单、轮播、排名展开和首页内赛程弹窗。所有页面入口采用锚点或首页内面板，不实现二级页面。品牌名、球队、人物、成绩、新闻和赞助商均替换为示例内容；保留麻将主题装饰文件。

## 页面顺序

1. 白色导航：桌面高 106px，手机高 55px。
2. 对战轮播：桌面四列，手机两列两行；两组对阵。
3. 介绍：居中标题、窄正文、两侧花牌。
4. 十条团队排名。
5. 四组个人榜：桌面两列，手机单列；默认各七条。
6. 浅灰赛程：默认八条，可以展开；已完成与待开始状态分开。
7. 三张新闻卡片：桌面三列，手机单列。
8. 留白与三个社交入口。
9. 黑色页脚：品牌、两项主要合作伙伴、十五项次级合作伙伴、两项供应商、十项主体单位、辅助链接及版权。

## 交互

- 轮播无自动播放，支持循环切换、分页、方向键及指针滑动。
- 桌面导航含悬停/键盘焦点下拉菜单。
- 手机菜单打开时锁定背景滚动，并在菜单内循环焦点；Esc 和遮罩均可关闭。
- 桌面个人榜按两表分组控制，手机端各表独立控制，状态可在断点切换后同步。
- 赛程弹窗采用原生 `dialog`，包括焦点返回、Esc 和遮罩关闭。手机单列内部滚动。
- 新闻图片悬停放大约 1.1 倍；绿色按钮悬停时填充收缩并显示绿色文字。
- 花牌：桌面位移为滚动距离/2，旋转角为正负滚动距离/10；手机分别为/10和/15。过渡约1秒。
- 减少动态效果时关闭花牌变换和长动画。

## 与参考页的有意差异

- 统一 CSS 和交互脚本的 767/768px 断点，并允许768–1039px的桌面内容缩放，避免原站1040px最小宽度带来的溢出。
- 内容图形使用独立SVG插画，首屏牌形和斜角用布局构建，不引入原站球队卡片图片。
- 标題、文案采用中文示例，因此行数、页面总高和少量纵向位置会与参考页不同。
- 会员面板使用点击开启的居中窗口，保留输入区与按钮视觉，不接入账号接口。
- 新闻和辅助入口使用首页内信息窗口，不实现外部目的页。
- 静态示例成绩不反映真实赛季，也不随系统日期变化。
